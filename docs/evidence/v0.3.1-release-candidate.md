## Remaining limitations

- Recovery: the failed-commit test reconciles a rewritten journal fixture; a
  commit that succeeds and then returns an injected error through the real
  failure path is not exercised (needs a fault-injecting proxy, v0.4.0).
- Ordering: "latest" is wall-clock `observed_at`; ties and clock rollback are
  ambiguous (documented in `docs/design/architecture.md`).
- Containerized `init` with no saved state creates a new Lakekeeper project;
  container operators must pass `ANTI_ENTROPATOR_PROJECT_ID` or persist the
  config directory to address existing data.
- The `main`-branch `:edge` image is published without a Trivy gate;
  `:latest` is written only by the release-tag path.
- Coverage measured without the Docker stack is 80.9 % lines (`cargo llvm-cov`,
  gate 50 %); the Docker-gated modules (`lakehouse`, `doctor`, `evolve`) are
  covered by Stack Tests, not by that number. `llvm-cov` reports "4 functions
  have mismatched data" (same function instrumented in more than one test
  binary); it persists after `cargo llvm-cov clean` and does not affect the
  gate.
